# 10.04 Antigravity coding-quality benchmark

**Status: proposed test; NOT yet executed.**

## Why this test is necessary

The earlier Stratum repair was independently scored **3/10**, but OmniRoute's retained logs do not identify its actual upstream provider/model. Most retained requests are connection tests. An alias such as `auto/best-coding` is not a measured quality score.

## Reproducible comparison

1. Keep the Stratum Downloader production checkout unchanged for the benchmark. The later assistant repairs were committed on a **separate review branch** and must not be counted as Antigravity's work.
2. Choose 2–4 currently accessible **refillable free** coding-capable candidates with reliable tool calls. Do not automatically spend one-time NVIDIA credits.
3. For each candidate, create a disposable, isolated Git worktree from the same baseline revision. Supply the same 15-defect Codex report, same task instructions and same context/token limits.
4. Send one identifiable, non-sensitive test request and verify the **requested alias, actual provider/model, HTTP outcome and any fallback** in Traffic Inspector.
5. Keep Antigravity compression disabled, preserve exact file paths and regression failures, and avoid model changes mid-step unless agent checkpoints are explicitly replayed.
6. Require each defect repair to reproduce the bug through the *real production caller*, add a behavioral test, run the complete suite, and report incomplete work.
7. Have Codex independently review the final diff and score fixed, partially fixed, untouched, regressions and false completion claims.
8. Rank results by repeated independent scores, not marketing labels or catalog size. Only then update default coding and reasoning routing; reserve scarce free credits for explicit manual use.

## Completion criteria

A successful benchmark must preserve a traceable upstream model, avoid paid inference, complete valid tool actions, retain task context through any fallback, and produce independently passing regressions without altering unrelated features.

**No automatic routing changes should be made until this evidence is available.**
