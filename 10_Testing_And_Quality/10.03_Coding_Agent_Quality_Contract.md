# 10.03 Agent contract for coding repairs

Every requested change must have:
1. Explicit input audit finding with file and line reference.
2. Reproduction or failing behavioural test against the real production entry point.
3. Minimal code patch and diff summary.
4. New regression that fails before and passes after.
5. Existing tests run, with exact PASS/FAIL/SKIPPED counts.
6. Independent security/ownership/cancellation/concurrency analysis.
7. No secret disclosure, paid-model surprise, unrelated refactor, or undocumented UI regressions.
8. Canonical project status update, with phase and unchanged out-of-scope tasks.
9. Commit/checkpoint and rollback.
10. Re-review of the exact diff and unresolved defects.

## Work package size
One issue group per agent pass; serial integration of fixes. The user wants correct work rather than large but unverified completion claims.

## Model choice
Use the best verified free model supporting tool calls and context. Reserve scarce credits only when explicitly authorized. Require local deterministic tests regardless of selected model.
