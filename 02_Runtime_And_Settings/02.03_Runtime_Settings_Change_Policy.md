# 02.03 Safe settings change policy

1. Confirm active DATA_DIR points to E: and the running port 20128 is bound to 127.0.0.1.
2. Obtain an integrity-checked SQLite online backup; never edit a copied, stale profile assuming it is live.
3. Record the exact change, intention, previous/new values (never the secret itself) and rollback in 11.04.
4. Prefer documented dashboard APIs or OmniRoute CLI with correct environment. Direct DB edits are a last resort and must follow application schema and setting revision conventions.
5. Do not restart if long-running agent streams are active. When restarting, pass correct DATA_DIR and OMNIROUTE_SERVER_HOST=127.0.0.1.
6. Verify server and inventory listeners, dashboard auth, sample free model completion, trace attribution, fallback and expected quota behavior.
7. Re-run the safe snapshot refresh in 13_Maintenance_Scripts and update pending issues.

### Do not do
Never run a generic restart without environment preflight; do not expose 0.0.0.0 or disable management authentication; do not add secret-bearing debug logs; do not copy live sqlite/.env to a GitHub repo.
