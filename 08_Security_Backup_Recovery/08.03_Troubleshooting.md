# 08.03 Troubleshooting matrix

| Symptom | Likely cause | Safe next checks |
|---|---|---|
| Dashboard works but models API 401 | Missing management auth/session/key | Sign in; do not disable auth |
| API Manager eye/copy icons missing | ALLOW_API_KEY_REVEAL false or stale page | Check flag, hard refresh; never create unauthenticated reveal |
| Port 20128 bound to 0.0.0.0 | Started with wrong host settings | Stop offending new instance; use pinned DATA_DIR and loopback |
| Config seems empty/missing | Wrong user-profile DB | Confirm active E: DATA_DIR, do not create new encryption secret |
| Inventory port 20129 not reachable | Companion server process stopped | Run one-click launcher, check server.mjs syntax and local listener |
| Auto route 503/no candidates | No qualified free models / strict policy | Inspect available pool and eligibility, do not silently route paid |
| Provider 429 | Free quota/rate limit exceeded | Respect reset/backoff, fail over only to equally verified free candidate |
| Provider 402/403 | Billing/access restriction | Stop retries; block suspect entry and investigate account |
| HuggingChat 502 | Upstream/service integration failure | Remove from critical fallback until a fresh successful test |
| Antigravity model appears but coding tools fail | Incomplete custom-model adapter/tool schemas | Test simple code task, streaming and tool calls; capture safe trace |
| Context lost after model fallback | Client did not replay project/agent state | Check session summary, tool history, model context, compression |
| CodeMap/Voice-PC-Agent auth failure | Key file not loaded, invalid key, or restricted model | Test dedicated key in local client without printing value |
| OmniRoute models show too many aliases | Built-in virtual routes and saved Combos mixed | Reference 03.01, hide redundant choices at UI layer rather than deleting functionality |

## Diagnostics policy
Collect timestamps, model alias, status code, sanitized trace ID, provider and client key name; never collect raw bearer headers or signed media URLs.
