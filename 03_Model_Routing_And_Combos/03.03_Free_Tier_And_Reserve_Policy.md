# 03.03 Strict free-tier policy and scarce-credit reserve

**Budget objective:** zero API billing and no unintentional conversion from free quota to paid credits.

## Provider classes
A. Refillable free allowance (e.g., eligible Gemini, Groq, Cloudflare, OpenRouter free routes): routine tasks after official pricing/billing checks.
B. One-time or scarce allowance (NVIDIA and any documented initial/trial-credit provider): explicit reserve use only.
C. Unknown charging / no hard stop / payment-required: reject from default auto routing pending independent verification.
D. Broken authentication/rate limit/5xx: quarantine from critical tasks until re-tested.

## Configuration evidence
- Saved settings hidePaidModels=true, freeAccessPolicy=strict, excludeTosAvoid=true.
- NVIDIA max_concurrent=1 was saved; provider remains connected and active.
- Auto-candidate per-client override table currently has 0 entries: explicit per-key reserve exclusions are NOT yet configured.
- Seven persisted Combos retain NVIDIA entries in some routes, including Code Free, Vision Free and Shal Vision. **These names are not guarantees of free-only behavior.**
- The 'auto' saved Combo also references AGY; source catalog flags AGY ToS status as avoid. Its legal/technical eligibility must be checked.

## Next critical implementation
1. Inventory actual billable accounts, eligibility per model, and hard-stop behavior.
2. Define explicit everyday provider allowlist and excluded reserved connection IDs, separately from classification suffixes.
3. Create reserved routing path with manual opt-in (prefer a distinct key or Combo and explicit audit).
4. Remove fragile/unverified entries from production saved Combos only after dependency verification and backup.
5. Fail closed if refillable free pool is exhausted; do not silently jump to a paid ID.
6. Verify actual fallback on simulated 429, 401, 502, timeout, context overflow and tool-call failure.
7. Set limits and alerts appropriate to trial quota; disabling top-up is provider-side, not just OmniRoute-side.

**Status:** Principles documented; universal reserve isolation and end-to-end zero-billing validation remain open.
