# 03.05 Planned minimal human-facing route presets

This is **PROPOSED**, not a record of changes already made to live Combos.

| Preset | Preferred eligibility | Use | Exclude |
|---|---|---|---|
| Everyday Coding | Verified refillable zero-cost models | Safe incremental fixes, syntax, tests | NVIDIA/scarce credit, paid-only |
| Best Coding | Highest tested coding quality among verified refillable free models | Root cause/complex refactor | One-time trial quota without opt-in |
| Reserved Coding | Explicitly tested top models with scarce free quotas | Rare, supervised critical tasks | Automatic background usage |
| Everyday Reasoning | Verified refillable free reasoning models | Analysis and planning | Paid-only |
| Reserved Reasoning | Top limited-credit reasoning models | Rare difficult problem | Auto background queries |
| Fast Summaries / Voice | Consistent fast refillable free text models | Obsidian, Elten AI, Edge-TTS/HTTS | Slower large coding models |
| Vision | Verified multimodal/image-text models | Visual PC and image workflows | Text-only fallback models |

## Proposed routing test metrics
Code repair pass rate with real production tests; 429 frequency; error rate; tool-call syntax; context-size fidelity; time to first token; quota-reset/cost observations; model switch impact.

Do not invent provider/model rankings before collecting actual A/B evidence.
