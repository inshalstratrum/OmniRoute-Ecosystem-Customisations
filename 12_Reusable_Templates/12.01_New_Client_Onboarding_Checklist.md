# 12.01 New OmniRoute client onboarding

- [ ] Identify app/repo, owner and workload.
- [ ] Confirm whether an existing key is used by this app (read-only audit).
- [ ] Set minimal allowed model IDs and saved Combos; exclude paid and reserved one-time quota by default.
- [ ] Verify provider hard stop and privacy terms; no credit-card dependency.
- [ ] Create dedicated named API key, store it in secret manager or ignored local .env.
- [ ] Keep actual key out of source, screenshots, chat, logs and public docs.
- [ ] Implement configurable base URL (localhost /v1), timeout, retry and error handling.
- [ ] Verify one small inference request and actual provider/model in Traffic Inspector.
- [ ] Validate 401, 429, 502 and exhaustion fallbacks without spending scarce quota.
- [ ] Verify context, tool/vision schemas and target language/format.
- [ ] Assign per-app usage/quota alerts.
- [ ] Record integration in folder 05 and add a dated change log entry.
- [ ] Store a tested rollback path and key rotation procedure.
