# 12.03 Documentation/release checklist

- [ ] No real tokens, credentials or secret-bearing database backups in staged files.
- [ ] .gitignore covers private .local files, .env, logs and database/WAL artifacts.
- [ ] Private machine path document remains ignored.
- [ ] Last sanitized snapshot refreshed and checked for secret material.
- [ ] All seven saved Combo dependencies reviewed before modification.
- [ ] Live service uses correct E: DATA_DIR and loopback bind.
- [ ] Management API endpoints require authentication.
- [ ] Free-only direct, virtual and persisted Combo routes tested.
- [ ] Reserved quota cannot be used by everyday route without explicit approval.
- [ ] Client keys and allowed models tested.
- [ ] Recent major bugs have production-caller regressions and independent audit.
- [ ] Change log, status, roadmap and rollback updated.
- [ ] README folder links present and serial numbering validated.
- [ ] Git history scanned for accidental previously committed secrets.
