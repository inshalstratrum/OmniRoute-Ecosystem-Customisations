# 14.04 Public Model Inventory Companion Package

This is a standalone localhost browser workspace for OmniRoute. It is a personal customization, **not an official OmniRoute integration**, and does not modify the installed OmniRoute package.

## Source files
- `14.01_Companion_Server.mjs`: Node HTTP proxy bound to 127.0.0.1:20129; forwards allowlisted management API routes to 127.0.0.1:20128
- `14.02_Inventory_UI.html`: model inventory interface and styling
- `14.03_Inventory_Client.js`: filtering, CSV, model tests and draft fallback planner

## Run (Node.js 24+, Windows)
First start OmniRoute locally and sign in to its management interface.
From this directory run:

```powershell
node .\14.01_Companion_Server.mjs
```

Open http://127.0.0.1:20129/models . Do not run another copy if port 20129 is already used.

## Safety
The companion listens on loopback, deliberately omits provider credentials from browser provider records and requires Origin checks on POST requests. The model test endpoint sends **real** inference that can spend quota; request permission explicitly before each test. The provider sync may modify model catalog records, so do not click it casually.

Management API read endpoints return HTTP 401 if an authorized session or management-authorized API key is missing. Do not disable OmniRoute authentication.

## Implementation limitations
This custom companion still needs full security review, provider/model ID compatibility tests, authentication flow improvements, and proper integration upstream before offering it as a production model-management dashboard. The planning list is not automatically applied to Combos.

Do not commit client API keys or connect this unaudited personal component to a network-facing instance.
