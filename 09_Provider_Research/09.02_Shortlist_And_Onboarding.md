# 09.02 Potential no-card/free-tier provider research

**Research candidates, not verified connected accounts or guaranteed current no-card offerings:**
- Mistral AI Studio: investigate current free API tier and model-specific quotas.
- Hugging Face Inference Providers: separate from HuggingChat; very small/free monthly credits; verify usage and signup.
- Cohere evaluation API: evaluate trial/evaluation tier; confirm whether it expires or needs billing credentials.
- Cerebras Cloud: fast inference with historically available free developer access; verify 2026 signup requirements.
- Kilo Code / gateway: free coding offerings; confirm if general OpenAI-compatible provider access is allowed.
- Cloudflare/Groq/OpenRouter/Gemini are already connected and are NOT missing.
- Other entries from installed OmniRoute free catalog (Arcee, Kilo, Pollinations, Ollama Cloud, public gateways, Mistral, etc.) require official confirmation of billing and terms; do not blindly connect or claim permanent free status.

## Explicitly exclude by default
Platforms that require a credit card, paid deposit or recurring subscription to get inference access; credits that automatically roll into paid billing; scraping or unofficial 'free' endpoints with avoid-classified terms.

## Never assume
Free-to-use website chat != an API license. Provider signup != verified token quota. No credit card at signup != permanent unlimited API. A model named 'pro' != a legal one-time reserve.

## Onboarding gate
Identity/source -> payment terms -> create account -> confirm hard stop -> store provider secret OUTSIDE vault -> connect -> discovery -> one controlled inference test -> routing eligibility -> monitoring and failure tests.
