# 13.01 Maintenance workflow

Run from a trusted Windows PowerShell with Python 3:

    $env:DATA_DIR = [Environment]::GetEnvironmentVariable('DATA_DIR','User')
    python 13_Maintenance_Scripts/13.02_Refresh_Sanitized_Snapshot.py
    python 13_Maintenance_Scripts/13.03_Verify_Publication_Safety.py

The snapshot generator reads only approved metadata columns from the active SQLite database and never serializes API secret values. It overwrites ONLY the explicitly generated snapshot files:
- 02_Runtime_And_Settings/02.02_Connected_Provider_Summary.md
- 02_Runtime_And_Settings/02.04_Sanitized_Config_Snapshot.json
- 03_Model_Routing_And_Combos/03.02_Seven_Saved_Combos.md
- 04_API_Keys_And_Clients/04.02_Client_Key_Permissions.md
- 07_Compression_Traffic_Quotas/07.03_Sanitized_Request_Summary.md

Static Markdown documentation is preserved by the initial builder. Review generated snapshots before staging to GitHub.

The validator checks minimum document set, numbered paths, file extensions, and basic possible secret patterns without printing matched text. It is a basic preflight, NOT a substitute for a professional secret scanner and human review.

For a new machine, first edit local-only path registry and ensure DATA_DIR points to the intended active DB before running refresh.
