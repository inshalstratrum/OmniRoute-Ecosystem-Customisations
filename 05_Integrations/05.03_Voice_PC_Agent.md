# 05.03 Voice-PC-Agent

## Current code and purpose
Backend: PC-Backend/agent_backend.py. Supports spoken/screen summarization, multi-application context and vision calls. Backend default port 8765.

## Change applied
- Dedicated key stored outside the repository in LOCALAPPDATA and loaded by a Python helper.
- Added Authorization header for text and vision requests, where previously the shown call sites sent no API key.
- Text model changed from auto to auto/chat:free.
- Vision model changed from a fixed named model to auto/vision (requires verification that the pool actually supports image input).
- Python compilation passed; original file backed up.

## Risk and acceptance checks
- Test server startup with correct DATA_DIR and localhost binding.
- Validate text summarization, screenshot/image input, assistive workflow, latency/timeout, Urdu summaries if relevant.
- Confirm vision fallback never lands on text-only models; verify image schema compatibility.
- Avoid echoing full screenshot or tool text into logs.
- Keep model budgets small for summaries; preserve tool/action instructions and explicit user permission for PC actions.
