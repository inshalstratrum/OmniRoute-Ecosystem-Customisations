# 05.05 Edge-TTS Voice Engine

## Current known integration
The tool has a local dashboard on port 5050. Its Python configuration includes OmniRoute as an available summarization provider; default model string in code was obsidian-voice. Its config validator limits OmniRoute URL to HTTPS or loopback HTTP and avoids URL-carried credentials.

## Role separation
Edge-TTS performs speech playback; OmniRoute supplies language-model summarization/briefing. A voice playback engine and an image/voice multimodal inference model are not the same feature.

## Recommended future setup
Use a dedicated key for HTTS/Edge-TTS if traffic attribution and limits warrant it. Consider fast free model and deterministic summary prompt; keep output tailored for spoken English/Urdu. Preserve on-screen action items, errors and commands accurately.

## Pending
Check live dashboard settings and credentials, verify running connection, response summaries, no accidental paid model or excessive transcript logging, and fail-safe operation when OmniRoute is unreachable.
