## Refresh cycle
- After every configuration change: update 11.04 change log; add verified evidence and a rollback note.
- After new provider connection: refresh safe snapshot, verify model IDs, hard-stop/billing policy, then test one candidate.
- After a critical bug or quota failure: add diagnostic context without tokens or sensitive prompts.
- Review docs before a public GitHub push using 08.02 GitHub checklist.
