# 00.01 Scope and ground rules

## Mission
One OmniRoute localhost gateway supports multiple client applications, while keeping their credentials, permissions, model policies, quotas, traces and failure domains distinct. Optimize for free, non-billable API usage and predictable long-running coding workflows.

## Documenting confidence
- **VERIFIED LIVE**: inspected running service, installation, or active SQLite data on 2026-10-19.
- **CONFIGURED**: settings saved to active database or code files; behavior may still require reload/test.
- **DOCUMENTED CLAIM**: inferred from installed OmniRoute source or earlier test reports.
- **PROPOSED / PENDING**: not yet changed or tested; do not present as complete.

## Non-negotiable safeguards
- No paid API spending; if a model lacks verified free hard-stop terms, fail closed.
- Treat NVIDIA's limited/one-time allowance as high-value reserve; preserve credits.
- Do not expose port 20128 to the LAN or internet. Existing local binding must remain loopback.
- Authenticate management operations. Never create anonymous secret-reveal routes.
- Prefer separate API keys for CodeMap, Voice-PC-Agent, Antigravity, Obsidian/Voice Assistant and future clients.
- Preserve production caller context, source files, checkpoints and behavioural regressions.
- Always make an integrity-checked SQLite backup before a configuration migration.

## Scope exclusions
This vault does not store actual secrets, raw provider tokens, individual prompts, complete traffic histories, source-code checkouts, or live database files. It does not assume every provider/model ID in the research catalog is currently valid.
